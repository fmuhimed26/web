CSS: المحددات Selectors

عنصر Element

ينسّق كل عناصر من نفس النوع.

p { color:red; }

معرّف ID

يطبّق على عنصر واحد فقط.

#box { width:100px; }

صنف Class

يمكن تطبيقه على عناصر متعددة.

.title { font-size:20px; }

شامل Universal

يطال كل العناصر.

* { margin:0; }
