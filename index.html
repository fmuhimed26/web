المحددات Selectors

عنصر Element

ينسّق كل عناصر من نفس النوع.

p { color: red; }

معرّف ID

يطبّق على عنصر واحد فريد في الصفحة.

#box { width: 100px; }

صنف Class

يمكن تطبيقه على عناصر متعددة.

.title { font-size: 20px; }

شامل Universal

يطال كل العناصر في الصفحة.

* { margin: 0; }

تُستخدم لشرح الكود دون التأثير على التنفيذ.

Colors الألوان — الطرق الأساسية

الطريقةمثال
اسم اللونred
HEX#ff0000
RGBrgb(255, 0, 0)

شرح موسّع مع أمثلة بصرية

- اسم اللون يستخدم مجموعة محدودة من الأسماء القياسية (مثل red, blue, green).
- HEX يمثّل اللون بستة أرقام سداسية عشرية: زوج للأحمر، زوج للأخضر، زوج للأزرق.
- RGB يحدّد المكوّنات بالأرقام من 0 إلى 255 لكل من الأحمر والأخضر والأزرق.

اسم اللون: red
HEX: #ff0000
RGB: rgb(255,0,0)

عن الشفافية: RGBA و HEX مع ألفا

يمكن إضافة قناة ألفا للشفافية: في RGB عبر rgba(r,g,b,a) حيث a بين 0 و 1، وفي HEX بإضافة زوجين للألفا مثل #RRGGBBAA.

rgba(255,0,0,0.5)
#ff000080

تدرّج لوني بسيط

linear-gradient(90deg, #ff0000, #00ff00, #0000ff)

مثال كود يوضّح الفروقات

/* نفس اللون الأحمر بثلاث طرق مختلفة */
.title-by-name { color: red; }
.title-by-hex { color: #ff0000; }
.title-by-rgb { color: rgb(255, 0, 0); }

/* إضافة شفافية */
.title-by-rgba { color: rgba(255, 0, 0, 0.6); }
.title-by-hex-a{ color: #ff000099; } /* حوالي 60% شفافية */
